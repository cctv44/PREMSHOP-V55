# PREMSHOP

Production-oriented digital premium account marketplace built with Next.js App Router, TypeScript, Prisma, Supabase PostgreSQL, NextAuth-ready auth surfaces, Supplier API integration, dark neon UI, cart/wishlist/order flows, and admin pages.

## Environment variables
See `.env.example`. Products are never stored permanently; runtime product data is fetched from the Supplier API.

## Commands
- `npm install`
- `npm run prisma:generate`
- `npm run build`
- `npm run dev`
